Side report

Reflective discussion of my module experience This term began with uncertainty. I entered as a novice, unsure how HTML, CSS, JavaScript, hosting, version control and debugging worked together. Early setbacks—broken layouts, unresponsive buttons, console errors—felt frustrating. Yet, each bug compelled me to learn browser dev tools, inspect elements, and trace errors. Over time, I built confidence. I now approach problems methodically: isolate, replicate, debug. The course pushed me to reflect regularly—what went well, what failed, and what to try next. That self‑refection helped me track steady progress despite occasional stumbling. Development of my personal portfolio website I dedicated most lab time in the module to developing my personal portfolio in the GitHub repo. I started with a simple HTML structure, gradually added sections: an about page, project gallery, and contact form. CSS styling evolved too. I began with plain colours and basic fonts, then moved towards a clean modern design. I experimented with flexbox for layout and media queries for responsiveness. JavaScript added interactivity: a mobile navigation toggle, smooth scroll, and form validation. Each small enhancement reinforced my understanding of how front‑end architectures work. Technical and UI design decisions For fonts, I chose "Inter" via Google Fonts its readability and clean aesthetic suited my minimal design. Colour‑wise, I used a dark navy background (#1A202C) with off‑white text (#F7FAFC) to create contrast. Accent links use a soft teal (#4FD1C5) for clarity and a modern feel. I was inspired by design styles on sites like CSS, Tricks and Awwwards, particularly their use of whitespace, clear typography, and responsive navigation menus. This guided my layout choices: generous padding, clear headings, consistent link hover styles. Going forward, I plan to refine accessibility, add alt text for images, and write automated tests. This term’s blend of building, debugging, reflecting, and iterating improved both my technical skills and my eye for clean, user‑friendly interfaces.
